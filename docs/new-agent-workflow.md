# New Agent Workflow

## If this is the first session for a client

1. Read `SKILL.md` and use the client copy of the Sheet. If no copy exists, give the client the [current template](https://docs.google.com/spreadsheets/d/1MYlCFQZYjfnFfNlWqQ9idDWg1jBpaDZCr6AjkfzzbgQ/edit) and the short instructions below. Do not write client data into the master.
2. Read `01 Brand`'s starting brief, the conversation and linked client-approved sources. The remaining tabs are optional inputs or agent workspaces, not mandatory homework. Older copies without a starting brief can use the equivalent information in their existing fields or the conversation.
3. Check kit status. Use the supplied approved kit, or ask for one kit/asset-folder link if absent. Follow `docs/brand-kit-workflow.md`; if there is no kit, propose a direction for approval.
4. Extract recurring context from the supplied material. Put sourced details in designated agent sections/notes and create `company_baseline.md` from its template. Preserve client answers, approved strategy and existing drafts. Label proposals and unknowns.
5. Compare the information available with the requested deliverables. Ask one concise grouped follow-up for essential missing facts or conflicting instructions only. Do not ask the client to finish every tab. Continue work that does not depend on the missing answers.
6. Briefly state your understanding of the audience, goal and approved brand direction. Proceed without an extra approval round when these are already clear; resolve material choices before dependent work.
7. Apply the research gate. Create `research_baseline.md` only for durable research. Select Strategy, Writing, Visual Prompt and/or Posting Time modes as needed.
8. Use the first request from `01 Brand` or the relevant Content Plan row. Write outputs to the existing agent-owned fields. A new client does not need to create a Content Plan row first.

### Client-facing handoff

“Make a copy of this template and complete the yellow answers in **01 Brand**. Share one brand-kit or asset-folder link; if you have none, say so. Examples and the other tabs are optional. If you don’t know an answer, write ‘Not sure—please help’. Share your copy and linked files with the operator account provided, then send your copied Sheet link back here.”

Supply the actual template link. Check access using available tools; a URL alone does not prove the client can open it. If access is restricted, have the owner grant the intended client viewing access before asking them to make a copy. Never invent the operator account or change permissions without authorization. Clients need not make private brand assets public.

### Completion and follow-up decisions

- A partially filled Sheet is usable when it contains enough information for the requested work.
- The starting page's completion indicator checks whether answers are present, not whether they are sufficient or approved.
- Empty optional examples or competitor tabs: proceed.
- Brand kit linked, separate font/color fields empty: extract the rules yourself.
- Essential offer details or conflicting logo versions: ask about those specific details only.
- No kit: propose a direction, request approval for that direction, continue independent work.
- Missing account analytics: use the posting-time guide's labeled test windows; establish the audience location/time zone before presenting local posting hours.
- No Sheets access: request access or an exported/uploaded copy, and provide clearly labeled results for manual pasting when possible. Never claim a write occurred without verification.

## If this is an existing client

1. Read `SKILL.md` only if not already loaded for the session.
2. Read the existing company baseline.
3. Read the research baseline only if relevant.
4. Read the target Content Plan row.
5. Check whether any baseline refresh trigger has occurred.
6. If not, do not reread the full Sheet.
7. Research only if the task hits a defined trigger.
8. Prepare the requested outputs. A complete package includes written content, a suggested visual prompt, and a suggested posting time with audience time zone and rationale.
9. Verify, review the content package, and write back to existing agent-owned fields. Keep prompts separate from post copy.

## If the client says the company information changed

Read only the affected Sheet tab/range where possible, update the affected baseline section, and record the refresh date.

## Standalone visual prompt request

When the user supplies a simple creative concept and only wants a suggested image prompt,
read the visual guide and provide the copyable prompt directly. Do not require a client
workbook or initialize baselines. The output is text for an image tool, not a generated image.

## Posting time suggestions

Use available audience context and account evidence. Read the timing guide for missing-data
fallbacks. Store suggestions in the agent-owned Draft section, preserve the client's Date / Slot,
and make clear that nothing has been scheduled or published.
