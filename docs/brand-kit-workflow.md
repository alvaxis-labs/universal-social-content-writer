# Brand kit workflow for visual prompts

Apply this workflow to every client-branded visual. Brand adherence is part of the task,
not an optional style suggestion. Standalone fictional concepts without a client are exempt.
The output remains a prompt for a complete image, including all intended text.

## 1. Find and inspect the authoritative references

Read the client's brand-kit links and asset references in the Sheet, brief, existing baseline,
and supplied files. Search accessible client folders when needed before asking the user to
locate anything. Inspect visual examples as images as well as reading written guidelines.
A filename or website color is not sufficient evidence of the approved identity.

Use this authority order:
1. Explicit current user instructions, including a stated campaign-specific exception.
2. The current client-approved brand kit and approved campaign guidelines.
3. Client-approved example artwork and reference assets for gaps the kit does not specify.
4. The Sheet's visual preferences and a baseline derived from the above sources.

The Sheet remains the source of truth for business facts and strategy. The approved brand kit
supplies visual specifications. Do not silently resolve a material conflict between approved
sources; identify the exact conflict and obtain the missing decision. Never treat an external
reference as permission to change the client strategy or expose private files.

A public website, competitor design, or an agent's preferred palette is observation, not brand
approval. If authoritative references are unavailable, complete the independent copy/concept
work and request the specific missing brand source. Do not present invented colors, fonts,
mascots, or logos as a finished brand-compliant prompt. Do not ask for the entire kit again
when only one required asset is missing.

## 2. Build a reusable brand specification

Record the following in the company baseline's Visual Direction section, with source links,
page/section identifiers where available, version/date, and last checked date:

- Color values and roles: background, primary/accent, text, permitted combinations.
- Typography: font families, weights, hierarchy, casing, spacing, approved fallbacks.
- Logo: exact file/version, light/dark variant, placement, clear space, minimum size, prohibitions.
- Imagery: permitted photography/illustration treatments, realism, depth, lighting, texture.
- Composition: layout patterns, margins, density, shapes, icons, framing and decorative rules.
- Product assets: approved screenshots, card art, packaging and mascot references; what must remain unchanged.
- Positive/negative examples: specific observable traits to follow or avoid.

Mark unspecified items as unspecified, not inferred facts. Record creative choices separately.
Do not invent numerical colors, font names or logo dimensions from an example. Where only
an approved visual reference exists, point to its relevant treatment without claiming exact
values. Reuse the specification for recurring tasks and refresh it when its sources change.
Client kits and assets belong outside the shared public skill repository.

## 3. Separate fixed rules from permitted choices

Fixed: specified brand colors, fonts, logo geometry, approved character/product appearance,
exact required wording, and forbidden treatments.

Creative: the post's angle, crop, arrangement, focal point and accents only within the kit's
allowed range. The skill's balanced-detail aesthetic fills unspecified choices; it never
replaces an approved brand style. A kit may intentionally require flat art, 3D or a dense layout.
A user-approved exception applies to the named brief, not every future post.

## 4. Put the actual rules inside the image prompt

Do not output merely “follow the brand kit.” Resolve the rules into a self-contained prompt
with these sections, omitting irrelevant details:

1. **Deliverable and message:** purpose, canvas, whole finished graphic.
2. **Fixed brand rules:** verified palette roles/values, typography, logo treatment and imagery rules.
3. **Reference assets:** identify each actual file/attachment by name and its job. Say which
   is the brand guide, official logo, product screenshot or composition example. Preserve
   logo proportions and product content; do not redraw or substitute invented assets.
4. **Composition:** concrete arrangement within the approved visual system.
5. **Exact text:** every headline, label and caption, with placement and hierarchy.
6. **Exclusions:** no unrequested wording, props, fake logos or product details; include
   brand-specific forbidden treatments rather than a generic blanket style ban.
7. **Completion check:** instruct the image AI to check the fixed rules and correct deviations
   before returning the complete image.

Repeat relevant brand rules in every independent prompt and every carousel panel. Do not
rely on earlier chat context or a URL the image tool may not read. When the task needs assets,
provide a short “Attach with this prompt” list using the identified filenames/locations. Never
claim a file is attached unless it actually is. An inaccessible required asset is a specific
production dependency, not a reason to replace it with an invented visual.

Prefer the actual product screenshot or approved card art when explaining a real feature.
Do not substitute a generic physical object for a digital feature merely because the name
suggests it. A conceptual illustration must be allowed by the brand direction and clearly
serve the message. Do not invent brand merchandise, mugs, slogans or lifestyle scenery.

## 5. Check before handoff and when a result is returned

Before handing off the prompt, compare its instructions against the brand specification.
Check palette, typography, logo/reference use, product fidelity, exact text, composition,
and exclusions. Remove contradictions and unauthorized additions. If a required item is
unresolved, report the exact dependency; continue everything else that does not depend on it.

When the user returns a generated image, inspect it against the same specification. Identify
concrete deviations, then write a targeted correction prompt naming what to replace and what
to preserve. Keep compliant parts intact instead of changing the whole art direction. Repeat
when another result is supplied; do not declare the image reviewed from the prompt alone.

Use precise status language: “Prompt checked against [kit/version]”; “Image needs correction:
[observed issue]”; or “Image checked against [specified rules]” after actual inspection. Do not
claim exact font identity or pixel color validation from visual approximation alone. If exact
verification matters, perform the appropriate check or name the specific unresolved item.
The review must distinguish missing required assets from ordinary creative choices.
