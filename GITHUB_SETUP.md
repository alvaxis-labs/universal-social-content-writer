# Suggested GitHub Repository

Suggested repository name:

`universal-social-content-writer`

Suggested location:

`Alvaxis Labs / universal-social-content-writer`

## Recommended visibility

The reusable skill pack itself can be public or private.

Do not commit real client baselines, private claims, internal strategy, or client Sheet exports to a public repo. The included `.gitignore` excludes generated client baselines by default.

## What to tell a future agent

If the repository is accessible to the agent, you only need to provide:

1. the repository URL
2. the client Google Sheet URL
3. the task

Then use the short prompt in `BOOTSTRAP_PROMPT.md`.
